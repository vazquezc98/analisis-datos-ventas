# 📊 Proyecto de Análisis de Ventas y Dashboard Interactivo

Este proyecto es un análisis exploratorio de datos (EDA) sobre ventas sintéticas de una tienda, acompañado de un dashboard web interactivo.

## 🚀 Ver Dashboard en Vivo
Puedes explorar el dashboard interactivo publicado en GitHub Pages desde el siguiente enlace:
👉 **[Ver Dashboard Interactivo](https://vazquezc98.github.io/analisis-datos-ventas/dashboard_cliente.html)**

---

## 📁 Archivos del Proyecto

- `ventas.csv`: Dataset con los datos de las transacciones (500 registros).
- `generar_ventas.py`: Script en Python para generar los datos sintéticos.
- `analizar_ventas.py`: Script que analiza los datos y genera los gráficos en formato `.png` (usando `pandas`, `seaborn` y `matplotlib`).
- `dashboard_ventas.py`: Script que genera el dashboard web interactivo (`dashboard_cliente.html`) embebiendo gráficos de `Plotly` y tablas dinámicas de `DataTables`.
- `dashboard_cliente.html`: Reporte visual interactivo listo para presentar.

---

## 🛠️ Tecnologías Utilizadas

- **Python 3**
- **pandas** (Manipulación y limpieza de datos)
- **matplotlib / seaborn** (Generación de gráficos estáticos)
- **Plotly** (Gráficos interactivos)
- **Bootstrap 5 & DataTables** (Diseño y tablas exploratorias en el HTML)
- **GitHub Pages** (Despliegue web)
